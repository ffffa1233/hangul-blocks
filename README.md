# 가나다 블록

만 3~5세 아이용 한글 놀이 교구. HTML 파일 하나로 폰·아이패드 브라우저에서 동작합니다.

## 기능
- **만들기**: 자음·모음(·받침) 블록을 골라 글자를 만들고, 그 글자로 시작하는 낱말을 그림과 함께 보여 줍니다.
- **쓰기**: 획순 애니메이션을 보고 손가락으로 따라 쓰면 획마다 채점해 칭찬해 줍니다.
- **듣고 맞히기**: 낱말을 듣고 그림 4개 중 고르는 5문제 한 판 놀이 (스티커, 효과음, 축하 화면).
- **단계**: 1단계 가나다 / 2단계 받침 / 3단계 쌍자음·복잡한 모음 / 스페셜 내 이름 쓰기.
- **아이별 정보**: 이름·생년월일·단계·스티커북·날짜별 기록을 아이마다 따로 저장 (브라우저 localStorage).

## 사용
`index.html`을 Chrome, Safari, 삼성 인터넷으로 열면 됩니다. 소리는 기기의 한국어 음성(TTS)을 씁니다.
아이폰·아이패드는 파일 앱 미리보기에서는 동작하지 않으므로 웹 주소로 여는 것을 권장합니다.

# 역할놀이 매표소 (`roleplay.html`)

아이와 역할놀이할 때 옆에 켜 두는 화면. 티켓·번호표가 출력되고, "삐빅! 입장하세요" 같은 효과음과 안내 음성이 나옵니다.

- **타고 가요**: 집 비행기, 비행기, 기차, 버스, 우주선
- **가게 놀이**: 식당, 푸드트럭, 마트, 미용실, 영화관, 놀이공원
- **일하는 사람**: 병원, 동물병원, 소방관, 택배, 세차장

**집 비행기**는 어른이 누워서 아이를 태워 주는 놀이용입니다. 티켓 받기 → 입장 → 안전벨트 → 조종석(이륙·흔들흔들·착륙 큰 버튼, 엔진 소리) 순서로 진행되고, 놀이 중에는 화면이 꺼지지 않습니다.

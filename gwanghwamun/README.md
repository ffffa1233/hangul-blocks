# 광화문 1/40 조립 모형

광화문 복원사업 도면을 바탕으로 문루와 육축의 부재를 1/40으로 줄여 3D 프린트용 STL로 만든 것입니다.
부재마다 따로 뽑아 끼워 맞추는 방식이고, 웹 조립대에서 순서대로 미리 조립해 볼 수 있습니다.

## 들어 있는 것

| 폴더 / 파일 | 내용 |
|---|---|
| `stl/` | 부재 STL 565종 (조립 단계별 폴더, 모두 합쳐 5,004개) |
| `개수표.md` | 단계별 부재 파일 · 개수 · 크기 · 쓰이는 단계 |
| `web/광화문_조립대.html` | 웹 조립대 (한 파일, 더블클릭으로 열림, 인터넷 연결 필요: three.js CDN) |
| `web/app.html` + `web/data.js` | 같은 조립대를 화면 코드와 데이터로 나눈 것 (수정용) |
| `미리보기/` | 작업 중 만든 미리보기 그림 |

## 범위

- 육축(홍예 3, 대문 6짝, 계단 2, 문루 둘레 담)
- 1·2층 기둥, 창방, 평방, 공포(주심포·주간포·귀포), 대량·충량, 장여·도리, 뜬창방
- 2층 우물마루
- 지붕 뼈대: 동자주·중도리·종량·대공·종도리, 추녀·사래, 서까래(선자연 포함), 부연

아직 없는 것: 평고대·개판·기와·마루(용마루 등)·잡상, 2층 판벽·판문, 2층 내부 계단, 현판, 해태, 양옆 궁장, 단청.

## 규칙

- 축척 1/40, 단위 mm, 치수는 적당히 반올림
- 끼움 여유 0.1은 구멍(장부 구멍) 쪽에 줌 (장부 3.0 → 구멍 3.2)
- 남는 벽이 0.5mm 이하가 되는 세부는 생략, 장식은 옛 모양 윤곽만
- 육축 조각은 3.0 각 다월핀으로 맞춤 (구멍 3.2, 깊이 6)

## 프린트 전 참고

- 아직 실물로 시험 출력하지 않았습니다. 기둥 하나와 창방·평방, 공포 한 벌을 먼저 뽑아 맞춰 보고 여유를 조정하는 것을 권합니다.
- 1.5mm보다 얇은 부재가 1,700개 넘게 있어(소로 등) 작은 부재는 레진 프린터가 유리합니다.
- 전체 크기 약 1.2 m × 0.4 m, 높이 약 45 cm.
